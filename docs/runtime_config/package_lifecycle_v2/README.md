# Managed package lifecycle candidate

Based on configurator f4146bedebb50559454954b8e20c9b641aeba616. Hardware acceptance pending.

Command 9 protocol 4 adds STATUS, QUERY and the four bounded operations 17 through 20. Protocol 3 CREATE and its historical wire grammar stay available. Lifecycle mutation requires a nonzero request token, incarnation, expected store generation, exact Config CRC and SHA-256, target ID and expected package revision. UPDATE takes one complete PackageBody, RENAME takes one UTF-8 name of 1–17 bytes, REORDER takes one uint32 rank (including zero), and DELETE takes no replacement fields. New complete replacements require matching row and display names and a supported plate. Semantic digest is SHA-256 of the NUL-terminated domain Glyph.Package.Lifecycle.v2 followed by the canonical envelope with field 2 omitted. Reuse of a token with a different digest conflicts. A matching durable result precedes stale generation checks. After evidence expires, an old token cannot re-execute.

The existing segmented publication order retains its exact baseline, Config, receipt and aggregate checks. Version 2 intents add the previous revision, row, RGB index and record hash in offsets 400, 404, 408 and 412. Non-delete mutations publish a new immutable revision for the same ID. A rename or rank edit copies the validated native wrapper byte-for-byte. DELETE increments the receipt revision and removes the owned row, optional RGB and directory entry. Surviving indices are compacted in order and backend defaults are adjusted to retain their destination. External references to deleted storage are refused. Executing or default packages cannot be deleted. A protected Config reference receipt must keep its original meaning.

Retire only the exact prior owned record between Config installation and terminal checkpoints. An interrupted operation is read-only and fenced. No startup compensation, generic write access, or mutable cross-request cache is introduced. Boot remains the activation boundary. Later repair starts with the lowest affected branch and repeats invalidated review, host proof, build and device cases.
