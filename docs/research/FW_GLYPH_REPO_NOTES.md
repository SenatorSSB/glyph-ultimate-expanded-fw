# FW-Glyph Repo Notes

FW-Glyph is the firmware realization fork/workstream for Glyph.

Important boundaries:

- It is not the canonical game-semantics source.
- It should not absorb the Senscope semantic-source pipeline.
- It is responsible for device-side realization, evaluation, and adapter behavior.

This repo should be treated as the place to test whether a neutral profile can be realized on the device, not as the place to define the semantics themselves.
