# Official Configurator Manual Import/Export Result Template

Status: `TEMPLATE_ONLY_NOT_A_RESULT`

performs manual official configurator import/export capture and records the
required artifacts.

- official configurator app/version
- operator
- import route
- export/back-and-forth route

- output artifact path and SHA-256
- comparison checker output
- reviewer notes
- pass/fail/inconclusive rows

Non-claims until a future result is recorded and inspected:

- no device write
- no WebSerial
- no runtime-loaded config
- no firmware flashing automation
- no hardware behavior validation
- no official compatibility claim
- no nunchuk validation

This file is template-only and is not a result.
