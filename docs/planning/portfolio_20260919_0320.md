### GP-PROV-009 — Reject hidden-dirty source before build and artifact custody

- **Objective/value:** Make the pre-build firmware identity and local artifact
  custody clean-snapshot checks immune to Git `assume-unchanged`,
  `skip-worktree`, and equivalent stat-cache concealment. This closes a direct
  source-to-artifact identity gap before the next H2/H3 candidate.
- **Current source evidence:** `builder_scripts/arduino_pico.py::git_identity`
  trusts `git status --porcelain --untracked-files=normal` and
  `tools/glyph_hardware_artifact_custody.py::require_clean_candidate_checkout`
  trusts `git status --porcelain --untracked-files=all`. Isolated repositories
  with changed tracked bytes hidden by either index flag produced empty status;
  the builder emitted a clean short SHA and custody accepted the checkout.
  The accepted GP-VAL-015 correspondence helper already demonstrates direct
  indexed byte/mode checks that reject these flags, so the failure class and a
  bounded implementation model are source-backed.
- **Implementation seam:** Reuse a small fail-closed tracked-entry verifier, or
  an equivalent directly reviewed implementation, in the build hook and
  custody precondition. Compare HEAD/index/working bytes, modes, file types,
  and symlink targets without trusting status optimizations; retain ordinary
  staged, unstaged, and untracked detection.
- **Scope/exclusions:** Builder identity helper, custody tool, focused isolated
  checkers/tests, and deterministic provenance/manifest/census/health/docs
  consequences only. No GP-VAL-011 ignored-state fingerprinting, dependency
  pin, build-selector change, firmware/runtime/table byte, artifact mutation,
  reproducibility claim, hardware reinterpretation, device write, or flashing.
- **Dependencies:** Current GP-BUILD-001, GP-ART-001, and GP-VAL-015 contracts
  remain materially unchanged; shared code must not weaken their different
  critical-input versus whole-clean-checkout purposes.
- **Validation:** Synthetic `assume-unchanged`, `skip-worktree`, restored-stat,
  mode, symlink, staged, unstaged, and untracked cases; exact clean pass;
  builder identity and custody rejection checks; canonical `glyph_mk6` build
  because the build hook changes; affected manifest/census/health and framework
  gates; independent review.
- **Risk/gates/confidence/readiness:** H1 build/custody safety; no hardware when
