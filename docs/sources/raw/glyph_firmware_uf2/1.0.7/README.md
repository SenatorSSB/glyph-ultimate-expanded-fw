# Glyph Firmware UF2 1.0.7 Raw Source Capture

Status: raw source artifact capture for docs-only analysis and recovery planning.

## Files

The files in this directory are official Glyph 1.0.7 firmware UF2 files supplied by the user:

- `GlyphFirmware-1.0.7.uf2`: user-facing Update firmware file.
- `GlyphFirmware-1.0.7-Clean.uf2`: user-facing Fresh Install / Clean firmware file.

These files are raw source artifacts for analysis and recovery planning. They are not generated by this repository, should not be modified, and are stored here only so future docs/source branches can compare known official firmware-update artifacts against generated custom artifacts.

Storing these files does not authorize flashing, upload, copy-to-device, or push-to-device behavior. This repository branch does not add a flashing workflow and does not perform hardware flashing.

## User-Provided Official Update Procedure

The following text was supplied by the user as official update procedure text. It is preserved as user-provided source text, not independently repo-verified official documentation:

> “Download the latest Firmware below, there are two options.
> - Update: Keep all controller profiles as is.
> - Fresh Install: Wipes all profiles and restores the factory default profiles.
> Connect your Glyph to a computer while holding the illuminated Menu button.
> The Glyph will enter programming mode, and appear as a USB drive named RPI-RP2.
> Drag and drop the downloaded .uf2 firmware file onto the RPI-RP2 drive.
> The USB drive will disconnect, closing the window and the Glyph will connect to the computer as a controller.”

## User-Facing Distinction

Based on the user-provided official update text:

- Update keeps controller profiles as-is.
- Fresh Install / Clean wipes profiles and restores factory default profiles.

The UF2 structure analysis in `docs/project/G12H_UF2_FORMAT_AND_FLASH_RANGE_ANALYSIS.md` shows that the Clean/Fresh Install file contains the same app segment as the Update file plus an additional high-flash all-zero segment. Connecting that extra segment to profile/config wiping is a strong inference from the file structure, the user-provided update text, and the repo build configuration, unless separately corroborated by official source or hardware observation.

## Handling Rules

- Do not edit these UF2 files.
- Do not regenerate these UF2 files from this repo.
- Do not treat these files as generated build outputs.
- Do not copy these files to a mounted device from an agent workflow.
- Do not use these files to flash hardware without separate explicit human approval.
- Do not use these files as proof that custom firmware is safe to flash.
