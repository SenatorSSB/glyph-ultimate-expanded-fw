# Agent Autonomy Tiers

## Tier 0: Documentation only

- Create, edit, and organize docs.
- Record sources, conclusions, and workflow rules.
- No code or behavior changes.

## Tier 1: Repo scaffolding

- Add scripts, manifests, ignores, and support files.
- Keep implementation untouched.
- Stay within build and tooling boundaries.

## Tier 2: Constrained realization experiments

- Propose or prototype firmware realization logic only when explicitly scoped.
- Preserve semantic-source separation.
- Do not change gameplay semantics.

## Tier 3: Explicit behavior change

- Only with direct user approval and clear scope.
- Requires careful verification and a full report.

This repository is currently operating at Tier 0 and Tier 1 only.
