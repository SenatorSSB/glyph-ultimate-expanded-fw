# Codex Workflow

1. Confirm the work is on `docs/senscope-glyph-baseline`.
2. Inspect repo status before editing.
3. Stay inside docs/setup unless the user explicitly expands scope.
4. Use repo-local PlatformIO via `./scripts/pio-local.sh`.
5. Prefer the baseline verification command `./scripts/pio-local.sh run -e glyph_mk6`.
6. Record source provenance instead of inventing missing artifacts.
7. Commit, push, stop, and report.

Do not use destructive git operations, and do not merge into `main`.
