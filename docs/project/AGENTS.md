# Project-Local Agent Instructions

The repository-root `AGENTS.md` is the primary instruction file. This nested
file adds no alternative authority.

Fresh chapter daemons must first read
`docs/agent_framework/FUTURE_DAEMON_BOOTSTRAP.md`. Follow root AGENTS.md for
capability-aware live Git access: known restricted-network unavailability
requires the permitted network-enabled path directly, without a repeated
expected-to-fail probe. Network permission widens no other authority.

Read the current project-local executable state only from
`docs/project/ACTIVE_AGENT_QUEUE.md`. Read role, authorization, liveness,
hardware, and publication contracts from `docs/agent_framework/README.md` and
`docs/WORKFLOW.md`.

Files in this directory labeled `SUPERSEDED_BY_AGENT_FRAMEWORK` are historical
compatibility pointers and must not be used as prompts or authorization.
