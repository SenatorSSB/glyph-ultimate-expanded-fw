The direction resolver uses `NeutralOnOpposite` in selected runtime. Horizontal opposites resolve to neither left nor right; vertical opposites resolve to neither down nor up. After that normalization, direction keys map as follows:

## Modifier Combinations And Selected Table Behavior

The selected runtime uses `RequireExactComboProfile`, so only exact enabled modifier masks resolve. The resolver contains a subset-fallback policy for other callers, but selected `SenscopePrototype` runtime does not use it.

| Active modifier mask | Physical combination under current assumptions | Exact combo profile present | Selected left-stick table | Selected runtime behavior |
| --- | --- | ---: | --- | --- |
| `0b000` | none of `rf2`/`rf3`/`rf4` | Yes, combo profile 0 | Table 0 | Resolve using table 0. |
| `0b001` | `rf2` | Yes, combo profile 1 | Table 1 | Resolve using table 1. |
| `0b010` | `rf3` | No | none | Lookup fails; selected runtime leaves neutral left stick. |
| `0b011` | `rf2` + `rf3` | No | none | Lookup fails; selected runtime leaves neutral left stick. |
| `0b100` | `rf4` | No | none | Lookup fails; selected runtime leaves neutral left stick. |
| `0b101` | `rf2` + `rf4` | No | none | Lookup fails; selected runtime leaves neutral left stick. |
| `0b110` | `rf3` + `rf4` | No | none | Lookup fails; selected runtime leaves neutral left stick. |
| `0b111` | `rf2` + `rf3` + `rf4` | No | none | Lookup fails; selected runtime leaves neutral left stick. |

## Neutral Direction 5 Behavior

Direction key 5 is present in both enabled tables and maps to `(128, 128)` in both tables. If no direction roles remain after the selected runtime's `NeutralOnOpposite` normalization, the direction resolver returns D5.

If the exact modifier mask resolves to table 0 or table 1, D5 returns `(128, 128)`. If the exact modifier mask does not resolve to a combo profile, the selected runtime does not apply a table entry and the left stick remains at the neutral initialization value `(128, 128)`.

## Fallback Behavior If Lookup Fails

`SenscopePrototype::UpdateAnalogOutputs()` initializes left-stick output to neutral before trying the resolver path. `TryResolveSenscopePrototypeLeftStickCoordinate()` returns `false` if direction resolution, modifier resolution, exact combo selection, table selection, or direction-entry lookup fails. In that case, `UpdateAnalogOutputs()` returns without changing the left stick from neutral.

Current selected runtime fail-closed result: left stick remains `(128, 128)`.

## Runtime Output Boundaries

The selected playtest runtime currently:

- updates only left-stick X/Y after a successful exact-table lookup;
- emits neutral digital outputs by setting `outputs.buttons = 0`;
- centers right stick/C-stick through `UpdateDirections(false, ..., kAnalogMin, kAnalogNeutral, kAnalogMax, outputs)`;
- sets `triggerLAnalog = 0` and `triggerRAnalog = 0`;
- does not call Force override resolution in selected runtime;
- does not call digital multi-output resolution in selected runtime;
- does not call layer-role map resolution in selected runtime.
