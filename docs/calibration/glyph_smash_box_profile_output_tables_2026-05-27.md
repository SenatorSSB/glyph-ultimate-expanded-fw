# Glyph Smash Box Profile Output Tables - 2026-05-27

## Scope

Canonical raw left-stick output tables for the identity-runtime Smash Box modifier implementation in `MODE_ULTIMATE`.

## Direction Convention

Direction IDs use numpad ordering:

- `1` = x left, y down
- `2` = x neutral, y down
- `3` = x right, y down
- `4` = x left, y neutral
- `5` = x neutral, y neutral
- `6` = x right, y neutral
- `7` = x left, y up
- `8` = x neutral, y up
- `9` = x right, y up
