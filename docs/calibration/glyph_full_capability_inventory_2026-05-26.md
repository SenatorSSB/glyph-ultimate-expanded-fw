# Glyph Full Capability Inventory (2026-05-26)

Scope: source-grounded inventory for the Glyph / HayBox firmware and configurator-facing backend workstream. This is not a Senscope app inventory, and it does not claim that Senscope neutral Profile JSON maps directly to Glyph JSON.

Status labels used below:

- source-confirmed: directly visible in repo source, docs, fixtures, or read-only tools.
- hardware-observed: recorded in `docs/calibration/glyph_ultimate_tilt_hardware_test_result.md`.
- inferred: derived from source structure, but not directly asserted by source comments/docs.
- unknown: not established by repo-local source or recorded hardware evidence.

## Unresolved Unknowns And Caveats

- unknown: exact external configurator JSON import/export treatment of omitted `activates` fields, beyond repo fixtures and the read-only parser preserving omission as `None`.
- unknown: whether active MK6 firmware includes a Nunchuk input source in the current build; source contains Nunchuk support but `config/glyph/common/src/config.cpp` only initializes `matrix_input` as an input source.
- unknown: exhaustive behavior preservation for C-stick/right-stick, triggers, SOCD matrix, RF5 negative case, and profile preservation after flash. The hardware result records these as not exhaustively tested or ambiguous.
- inferred: the same `Button` enum underlies physical scan IDs and logical post-remap IDs. This is clear from runtime data flow, but documentation must still label pre-remap versus post-remap usage.
- source-confirmed absence: no runtime backend adapter is currently implemented to consume Senscope neutral Profile JSON directly.
- source-confirmed boundary: no repo-local push-to-device automation was added or needed for this inventory.

## Hardware-Observed Versus Source-Confirmed

Hardware-observed:

- Native Tilt1/Tilt2 output tables passed on hardware for the recorded artifact.
- Both-held `LT1+LT2` produced stable existing combined behavior offsets.
- Mini-screen offsets convert to raw coordinates by adding 128.
- Manual UF2 bootloader flow through RPI-RP2 worked in the recorded test.

Source-confirmed:

- Runtime Tilt/Tilt2 code consumes logical `inputs.lt1` / `inputs.lt2` after remap.
- Remap runs before SOCD, and both run before Ultimate output generation.
- `BTN_UNSPECIFIED` is a no-op target for button setting and can disable a physical input once that physical button is marked remapped.
- On-device config storage is protobuf-in-LittleFS with size/CRC validation.

Not claimed:

- No unsupported hardware behavior.
- No Smash gameplay semantics.
- No coordinate legality/banned-coordinate claims.
- No direct Senscope neutral Profile JSON to Glyph JSON equivalence.
