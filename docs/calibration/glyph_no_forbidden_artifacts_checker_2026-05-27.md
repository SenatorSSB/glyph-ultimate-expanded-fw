# Glyph No Forbidden Artifacts Checker - 2026-05-27

Purpose: protect branch hygiene before hardware build/test work starts.

This checker is a local prehardware hygiene gate only. It does not prove runtime behavior, hardware readiness, firmware safety, flashing approval, or preservation verification.

## What It Checks

- tracked forbidden generated/build artifacts
- visible untracked generated artifacts as warnings

Tracked forbidden generated/build paths fail because committed generated files, local environments, and firmware/build outputs would pollute the branch before manual hardware preparation.

Visible untracked generated paths warn instead of fail because local builds may create artifacts during hardware prep. They are acceptable as local state only and must not be committed.

## Source/Reference Firmware Inputs

The checker bans tracked generated/build artifacts. The existing tracked UF2 files under `docs/sources/raw/glyph_firmware_uf2/1.0.7/` are source/reference inputs, not outputs generated by this workflow.

The allowlist is explicit and narrow:

- `docs/sources/raw/glyph_firmware_uf2/1.0.7/GlyphFirmware-1.0.7-Clean.uf2`
- `docs/sources/raw/glyph_firmware_uf2/1.0.7/GlyphFirmware-1.0.7.uf2`

New tracked firmware binaries must be reviewed and documented before being added to the allowlist. A future tracked `.uf2` outside this explicit list should fail until reviewed.

## Local Artifact Notes

- `.pio` may exist locally after a build but must not be committed.
- `.venv` may exist locally but must not be committed.

## What It Intentionally Does Not Do

- does not delete files
- does not build firmware
- does not flash hardware
- does not push to device
- does not approve hardware testing
- does not claim preservation verification

## Command

Run from repository root:

```bash
.venv/bin/python tools/check_glyph_no_forbidden_artifacts.py
```
