# Glyph Export Corpus Directory

This directory is reserved for **real, matched-version configurator export captures**.

Rules:

- do not add synthetic/fake exports;
- keep one corpus per subdirectory (`<corpus_id>/manifest.json` + `fixtures/`);
- keep captures immutable once committed;
- use `docs/calibration/glyph_profile_config_export_corpus_manifest_TEMPLATE.json` as the manifest starter.

No flashing/push automation is defined here.
