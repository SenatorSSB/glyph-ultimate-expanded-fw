# Custom Ultimate Mode Plan

The first implementation should be a minimal custom Ultimate mode shell or an exact-coordinate resolver prototype.

It should not be a direct ESAM1 port.

Preferred direction:

- preserve the realization boundary
- keep neutral profile intent external
- validate whether exact coordinate outputs and safe flipper transforms are feasible
- defer deeper gameplay semantics work to Senscope

This is a design note only; no firmware behavior changes are defined here.
