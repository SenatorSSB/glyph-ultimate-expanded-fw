# Exact host schema fixture

This GP-VAL-026 fixture supplies only the dependency closure needed to compile
the existing exact-production custom-modifier characterization on a clean
checkout. It is not a firmware include path, a schema change, a dependency
upgrade, or a handwritten schema. The compiler needs `config.pb.h` and `pb.h`;
the other files establish source and license correspondence.

`provenance.json` records full immutable commits, original Git blob identities,
SHA-256 hashes, generator/header versions and the exact tracked Glyph selector.
The checker independently pins the entire provenance file's SHA-256, verifies
each file's bytes and Git blob, checks regular tracked-file custody and the
unchanged selector, and compile-asserts the generated 20-modifier extent.
Changing metadata along with fixture bytes cannot select a different schema.
Any future fixture revision requires separate source authorization and review.

The bounded regeneration used the following command from a temporary directory
containing the exact `config.proto` and `config.options`, with the immutable
Nanopb checkout and installed host Python selected explicitly:

```text
python -B <nanopb-commit>/generator/nanopb_generator.py \
  --output-dir <temporary-output> --error-on-unmatched \
  --proto-path <temporary-proto-directory> config.proto
```

Regeneration is intake evidence only. Normal checks neither run the generator
nor download dependencies. Narrow `.gitattributes` entries preserve the exact
vendored line endings and original license whitespace; repository-wide
whitespace policy is unchanged. All output binaries and adversarial fixture
copies are created outside the checkout and automatically removed.
